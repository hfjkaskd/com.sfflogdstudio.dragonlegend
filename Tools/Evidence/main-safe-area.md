These observed relationships justify using the SpinPlayfield root for this part of the original Node's adaptation, without insetting MainBackground or the active popup group.

`BuildMainSafeArea.Attach` restores `RecoveredScreenAdapt` on SpinPlayfield and removes the formerly isolated MoreWildEntry adapter so that this branch receives one inset, not two. The full SpinPlayfield builder calls it, and the standalone MoreWild SaveEntry builder calls it after refreshing the entry. MoreWild retains the authored Node/Tubiao transform structure but delegates adaptation to the shared parent. The runtime adapter remains the same native-equivalent Awake/OnEnable/Start implementation; no new update polling or runtime static layout creation is introduced.
